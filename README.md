# Цей репозиторій призначений для лабараторних робіт з TS

[шаблон сайт](https://www.papayatemplates.com/huddle/)

На сторінку додано інтерактивність: зображення отримали легку анімацію при наведенні, іконки — плавний ефект виділення. Картки спікерів стали клікабельними та підсвічуються при ховері. Реалізовано модальне вікно, яке відкривається з даними вибраного спікера, блокує прокрутку фону й завжди відкривається зі скролом зверху. Модалка має власну прокрутку, закривається по кліку на фон або кнопку, а після закриття сторінка повертається до попередньої позиції.
